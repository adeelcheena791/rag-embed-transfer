\section{Experimental Setup}
\label{sec:setup}

\subsection{Data}
\label{sec:data}
We use the BEIR version \citep{thakur2021beir} of Natural Questions \citep{kwiatkowski2019nq}.
Its test split has \NUM{n.judged} queries with at least one judged relevant passage.
EM needs short reference answers, which BEIR lacks, so we join each BEIR query to NQ-open \citep{lee2019latent} by exact match of normalised question text, and keep a query only if all matching NQ-open entries share one answer list.
The join keeps \NUM{n.joined} of the \NUM{n.judged} queries (\NUM{join.rate}\%) and finds no ambiguous matches (Table~\ref{tab:T2} in Appendix~\ref{app:tables}).
All answer-level results use these \NUM{n.joined} joined queries.
Retrieval results use them as the primary set and all \NUM{n.judged} judged queries as a secondary check.
A fixed seeded order of the joined queries defines every subsample: the first \NUM{n.judge} for the judge, the first \NUM{n.idk} for the IDK prompt and the first \NUM{n.det} for the determinism check.

\subsection{Hardware and budget}
\label{sec:hardware}
All runs use free Kaggle sessions, each with two Tesla T4 GPUs (15\,GB each) and a 4-vCPU Intel Xeon CPU at 2.0\,GHz with 31\,GB of RAM.
Encoding, retrieval and reading use one T4.
The judge uses both T4s with tensor parallelism.
We measure all CPU costs on the 4-vCPU CPU of the retrieval session.
The study used no paid compute, API or data, and its monetary cost was zero.

\subsection{Models and software}
\label{sec:models}
We pin all models, including the reader and the judge, to fixed revisions (Table~\ref{tab:TC4}).
Retrieval uses sentence-transformers 5.4.1, FAISS 1.15.1 and bm25s 0.3.11; reading and judging use vLLM 0.30.0.
As a sanity check, our encoding pipeline reproduces the model-card SciFact nDCG@10 of bge-small, bge-base, bge-large and e5-base within \NUM{scifact.maxdiff}. In a post-hoc check, our SciFact nDCG@10 for Qwen3-Emb-0.6B (\NUM{scifact.qwen.ours}) lies within \NUM{scifact.qwen.diff} of its MTEB leaderboard value (\NUM{scifact.qwen.mteb}, earlier model revision).
Code, configuration files, pinned revisions and raw outputs are provided as anonymised supplementary material and will be released publicly upon publication.

\subsection{Pre-registration and deviations}
\label{sec:deviations}
We wrote a design document before the pilot and added dated addenda before each main-run stage.
Appendix~\ref{app:prereg} lists every deviation from it, including a changed join gate, a changed sub-corpus rule, a cut ablation, a dropped RAGAS cross-check and two execution errors that did not change any data.
