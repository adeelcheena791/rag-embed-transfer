# IP&M submission guide (Roman Urdu)

Journal: Information Processing & Management (Elsevier). Review: double-anonymised.
Article type: Research paper (form mein naam "Research Paper" ya "Full Length Article" ho sakta hai).

## Submit se PEHLE (zaroori)
1. GitHub repo public karo: github.com/adeelcheena791/rag-embed-transfer → Settings → General →
   neeche "Danger Zone" → Change repository visibility → Public. Warna editor link nahi khol sakega.
2. Is folder ki files apne computer par download kar lo.

## Files aur unka upload type

| File | Upload type (form mein) | Reviewer dekhega? |
|---|---|---|
| 01_Cover_letter.docx (ya .pdf) | Cover Letter | Nahi, sirf editor |
| 02_Title_page.docx (aur .pdf) | Title Page (with author details) | Nahi |
| 03_Manuscript_anonymised.pdf | Manuscript (anonymised) | Haan |
| 04_Manuscript_LaTeX_source.zip | LaTeX Source Files (editable source) | Haan |
| 05_Highlights.docx | Highlights (agar form maange) | Haan |
| 06_Declaration_of_competing_interest.docx | Declaration of Interest Statement (agar alag maange) | Nahi |
| 07_Text_for_submission_form.txt | Upload NAHI karni; title, abstract, keywords yahan se copy-paste | - |

Note: figures aur tables manuscript PDF aur LaTeX zip ke andar hain; alag upload ki zaroorat nahi,
jab tak system khud na maange (maange to zip ke `figs/` folder se PDF figures do).

## Steps
1. ScienceDirect par journal page kholo → "Submit your article". Elsevier account banao ya login karo
   (Gmail ya university email). ORCID link karne ka option aaye to 0009-0006-8541-4422 link kar do.
2. Article type: Research Paper / Full Length Article.
3. Files upload karo (upar wali table ke type ke mutabiq).
4. Title, abstract, keywords: 07_Text_for_submission_form.txt se copy-paste.
5. Author: sirf aap, corresponding author. Email: muhammadadeel167@stu.zzu.edu.cn, Zhengzhou University.
6. Questions ka jawab:
   - Funding: No / none.
   - Competing interests: None.
   - Generative AI used: Yes, declaration manuscript mein hai (references se pehle).
   - Data availability: data/code repository mein hai; link title page par.
   - Previously published / under review elsewhere / preprint: No.
   - Suggested reviewers: optional. Agar lazmi ho to sirf asli log do jin ke papers hum ne cite kiye hain
     aur jin ka aap se koi taluq nahi; kisi ka naam ya email khud se mat banao.
7. System ek combined PDF banayega. Use poora khol kar dekho: saare tables, figures, references theek
   hain, aur manuscript mein aap ka naam kahin nahi.
8. Approve / Submit. Confirmation email aayegi; manuscript number sambhal kar rakho.

## Submit ke BAAD
- arXiv ya kisi aur jagah preprint mat daalna jab tak faisla na aa jaye (double-anonymised review).
- Repo mein naya commit ya badlav review ke dauran zaroori na ho to mat karo.
- Pehla faisla (desk) aksar kuch dino mein aata hai; review ke baad ka faisla kuch hafte/mahine le sakta hai.
