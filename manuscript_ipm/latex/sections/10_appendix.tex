\section{Reader prompts}\label{app:prompts}
Each prompt was rendered with the reader's own chat template. Passages appear in rank order as ``[$i$] title'' followed by the passage text on the next line, separated by blank lines.

\paragraph{A1 (with passages)} System: \emph{``You are a question answering assistant. Answer the question using the passages provided. If the passages do not contain the answer, give your best short answer anyway. Reply with the answer only, as a short phrase of a few words, with no explanation.''} User: \emph{``Passages: \ldots\ Question: \{question\} Answer:''}

\paragraph{A2 (closed book)} System: \emph{``You are a question answering assistant. Reply with the answer only, as a short phrase of a few words, with no explanation.''} User: \emph{``Question: \{question\} Answer:''}

The gold-passage condition uses A1 with the gold passages only.
